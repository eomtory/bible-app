성경 카드 관리자

새 구조는 `verses / cards / aliases / images`만 사용합니다. 카드 문구는 직접 관리하고, 이미지 파일명 표준화가 안 되는 경우만 `imageKey` 또는 `Aliases`로 보정합니다.

구절 목록

왼쪽에서 절을 선택하고 오른쪽에서 편집합니다.

새 앱 구조로 초기화했습니다. 내보내기 후 backup 폴더에 덮어쓰고 업데이트하세요.

구절 정보

카드 편집

카드 문구는 화면에 숨겨질 단위입니다. `imageKey`가 비어 있으면 카드 문구 자체로 이미지 파일명을 찾습니다.

Aliases

`variant base` 형식으로 입력합니다. 규칙으로 안 잡히는 것만 추가하세요.

Image Mappings

`key path` 형식으로 입력합니다. 파일명 추론이 안 될 때만 등록하세요.
