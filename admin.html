성경 카드 관리자

구절을 저장하면 자동으로 공백 단위로 분리하고, 필요한 곳만 앞 단어와 붙이기로 조정합니다. 그다음 카드 계산을 돌려 이미지 파일명 규칙, 이미지 매핑, Aliases를 순서대로 적용합니다.

구절 목록

왼쪽에서 절을 선택하고 오른쪽에서 분리/매핑 상태를 확인합니다.

구절 저장 -> 자동 분리 -> 붙이기 체크 -> 카드 다시 계산 -> 내보내기 순서로 사용하세요.

구절 정보

분리된 단위

자동 분리 후 필요한 곳만 앞 단어와 이어 주세요. 예: 미워하는 + 것은 -> 뒤 단어에 체크.

카드 계산 결과

버튼을 누르면 규칙 기반 정규화 -> 이미지 매핑 -> 파일명 추론 순으로 매칭합니다. 안 되는 것만 Aliases로 보정하면 됩니다.

Aliases

경외하는 것은, 경외처럼 한 줄에 변형, 기준 형식으로 입력합니다. 탭, 쉼표, ->, | 모두 가능합니다.

Image Mappings

경외, BibleCards_Images/경외.png처럼 한 줄에 기준, 경로 형식으로 입력합니다. 파일명 자동 추론이 안 되는 경우만 등록하세요.

Aliases / Image Mappings 관리

가나다순으로 정렬되며, 검색과 삭제를 여기서 할 수 있습니다.
